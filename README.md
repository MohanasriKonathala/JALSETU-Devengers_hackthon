# 💧 JALSETU

### Water should flow where it matters most.

JALSETU is an intelligent water allocation and reuse decision-support platform. It demonstrates how water consumption, shortage risk, potential non-potable availability and demand can be connected in one interface.

## Features

- Water Intelligence Dashboard
- Consumption anomaly signals
- Shortage-risk visualization
- Interactive Water Map
- Water Matching Engine
- What-If Simulator
- Potential freshwater avoided calculation
- Responsive hackathon-ready UI

## Tech Stack

- React
- Vite
- JavaScript
- Recharts
- Lucide React
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

For production build:

```bash
npm run build
```

## Important note

The application currently uses simulated demonstration data. It is a decision-support prototype, not an operational water-transfer system. Actual water reuse requires water-quality testing, treatment, infrastructure and applicable regulatory verification.

Monitor → Detect → Predict → Match → Simulate → Impact
